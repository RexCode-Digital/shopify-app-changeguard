# Governance

ChangeGuard is maintained by its repository owner. External contributor pull requests receive maintainer review before merge.

The owner has explicitly delegated routine repository maintenance and release execution to an automated agent. Maintainer-authored or delegated maintenance may use owner/admin merge after all required automated gates are green, with no unresolved review threads and no security-check bypass. The project must never claim that a human reviewed a change when that did not happen. Security-sensitive semantic changes still require explicit maintainer scrutiny.

Changes that expand Shopify semantics should cite current official Shopify documentation and include positive, negative, unchanged, and redaction tests.
