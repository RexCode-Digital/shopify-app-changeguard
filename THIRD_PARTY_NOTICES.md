# Third-party notices

The generated GitHub Action bundle in `dist/action/index.js` contains third-party code. Its companion `dist/action/licenses.txt` is generated by ncc from the actual bundled dependency graph and carries the full licence texts for bundled modules. The bundle also preserves source comments identifying `formdata-polyfill` and `ws`; their exact versions are not recorded separately in the repository lockfile. `undici` is resolved as version 6.29.0 in `package-lock.json`. The companion inventory is included with the repository's Action distribution; the npm package does not include the GitHub Action bundle.
